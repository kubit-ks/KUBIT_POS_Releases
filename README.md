# KuBIT POS — Instalimi

Shkarko dhe instalo **KuBIT POS** nga këtu. Pa nevojë për .NET runtime; kodi burimor është privat.

## Instalimi (klienti)
1. Hap **[Releases / latest](https://github.com/kubit-ks/KUBIT_POS_Releases/releases/latest)**.
2. Shkarko **`KubitPOS-Setup-<version>.exe`**.
3. Hape skedarin → **Install** → POS instalohet me shortcut në Desktop & Start Menu.

> Windows mund të shfaqë "Unknown publisher" (installer i panënshkruar) — kliko **More info → Run anyway**.

Alternativë manuale: `KubitPOS-<version>-win-x64.zip` — shpaketo dhe hap `POS.exe`.

---
Këtu publikohen vetëm paketat e instalimit (binarë të kompiluar), automatikisht nga CI e repos private `KUBIT_POS_2026`. Asnjë rresht kodi burimor nuk ndodhet këtu.
